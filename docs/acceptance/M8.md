## 3. Scoop 本机验证记录（T8.3 核心证据）

- 环境：Windows 11（x86_64）；Scoop **v0.6.0**（用户级安装到 `~/scoop`，不涉系统级改动）
- 清单：`packaging/scoop/forgedesk.json`（v1.1.3，hash 与 Release 的 `SHA256SUMS` 逐字一致）
- 执行与结果：

```text
> scoop install .\packaging\scoop\forgedesk.json
Installing 'forgedesk' (1.1.3) [64bit] from 'E:\Projects\ForgeDesk\packaging\scoop\forgedesk.json'
Downloading https://github.com/Ember1414/forgedesk/releases/download/v1.1.3/ForgeDesk_1.1.3_windows_x64_portable.zip (7.8 MB)...
Checking hash of ForgeDesk_1.1.3_windows_x64_portable.zip... OK.
Extracting ForgeDesk_1.1.3_windows_x64_portable.zip... Done.
Linking ~\scoop\apps\forgedesk\current => ~\scoop\apps\forgedesk\1.1.3
Creating shim for 'ForgeDesk'.
Making C:\Users\TD\scoop\shims\forgedesk.exe a GUI binary.
Creating shortcut for ForgeDesk (ForgeDesk.exe)
'forgedesk' (1.1.3) was installed successfully!
```

- 安装形态核对：`apps/forgedesk/current/` = `ForgeDesk.exe` + `LICENSE` + `README-portable.txt`；
  shim `shims/forgedesk.exe`→`forgedesk.shim` 指向真实 exe；开始菜单出现 `ForgeDesk.lnk`；
  `scoop-install.json` 记录安装来源。
- 卸载核对：`scoop uninstall forgedesk` → apps 目录、shim、快捷方式全部移除（无残留）。
- 未做的部分（如实标注）：**没有从 shim 启动 GUI**（避免在验证会话里弹窗；
  应用本身的启动属 M7 遗留的实机验证项，不因本渠道改变）；**没有做"自有 bucket 仓库"路径**
  ——它需要一个 GitHub 仓库（人类创建），但清单内容与安装链路完全一致。
- 环境噪音与处置：首次安装会话中 Scoop 安装器在 `main` bucket clone 阶段卡死
  （网络原因），改用手工补 shim 后 `scoop install` 正常；该问题与 ForgeDesk 清单无关，
  bucket 未安装不影响本地清单安装（`scoop install <path>` 不需要 bucket）。

   `brew install --cask` 的真机验证在拿到 Mac 后补做（与 ADR-005 的既有约定一致）。
4. **创建 15 个 Issue**：按 `docs/GOOD-FIRST-ISSUES.md` 逐条创建并打标签（标签需先创建，命名见该文件 §3）。

7. **升级 + 回滚演练**：下次版本发布时执行并回填本文件 §1 第 10 条。
8. **推广材料**（T8.9）：视频/文章需要真机演示与个人表达，仍待人类排期。
