## 4. 需要人类执行的真实 GitHub 联调（唯一未闭合项）

前置：一个有 `repo` 权限的测试仓库（**建议用自己名下的空仓库**），一个 PAT
（classic，勾 `repo`）。执行顺序：

1. 只读冒烟（**安全，可随时跑**）：
   `GITHUB_TOKEN=<pat> TEST_REPO=<owner/repo> cargo test -p forgedesk-services --test real_github_smoke -- --nocapture`
   期望：打印一行"真实 GitHub 冒烟通过：…"，并且没有任何写操作。
2. 应用内联调（**会产生写操作，需明确授权**）：
   - 代码托管 → 仓库列表：搜索/星标/Fork/README 渲染；
   - 拉取请求：打开一个**自己创建的**测试 PR → 行内评论 → 提交 review（Approve）；
   - 合并：选策略（merge/squash/rebase）+ 勾"删除源分支" → 确认合并 → 回到仓库页
     确认分支已删（可再推一条提交把分支恢复）；
   - 议题：新建 → 改状态 → 指派 → 评论；
   - 流水线：跑一次 workflow → 查看日志 → 取消 → 重跑；
   - 额度：构造限流（或直接读横幅上的剩余额度）→ 观察降级提示与"刷新"。
3. 把每一步的结果（通过/不通过 + 现象）回填到本文件 §1 第 4 行，并把联调仓库与
   日期写在这里：**（待填：仓库 / 日期 / 执行人）**。

边界：联调只允许在**自己名下的测试仓库**进行；`docs/acceptance/T2.6-github-checklist.md`
里的只读项可以先跑（它不写任何数据）。

## 6. 本轮发现与修复的缺陷

**无新增 P0/P1**。两处与"报告/测试"自身有关的事实记录如下（都不是产品缺陷）：

1. **契约测试抓到的接口漂移（已修，记录在 T4.12 提交里）**：星标端点是
   `PUT /repos/{o}/{r}/starred` 而不是 `/user/starred/{o}/{r}`——正是契约测试存在的
   意义（假设的路径与实现的路径不一致，不写契约测试就只能等联调时才发现）。
2. **本文件的 E2E 曾把一个 mock 写错而误报崩溃**：`e2e/github.spec.ts` 最初让
   `credentials_status` 落到"未识别的命令返回 `null`"分支，设置页当场抛
   `Cannot read properties of null (reading 'mode')`。核对 `docs/API.md` 与
   `crates/commands/src/credentials.rs` 后确认该 DTO **非空**——错的是 mock 而不是产品，
   已按真实形状补齐（同时补了 `credentials_list` / `credentials_ssh_inventory`）。
   记在这里是因为它给出了一条经验：**mock 必须按契约形状给，不能用"兜底 null"糊过去**，
   否则 E2E 会把 mock 的偷懒报成产品崩溃。
3. **外壳用例的两个既有红灯（本轮修复）**：跑全量 E2E 时发现
   `e2e/shell.spec.ts` 有 2 个用例早已红——都没人发现，因为私有阶段 e2e.yml 未启用、
   平时只跑单文件：
   - `every sidebar entry opens its own page`：T3.10 加了侧栏项"操作历史"之后，
     `getByRole('link', { name: '历史' })` 会同时命中"历史"与"操作历史"（strict mode
     violation）。修法是给选择器加 `exact`；
   - `route table entries resolve`：路由表用例逐个打开每个导航项，而"代码托管"各页的
     读取命令落在 mock 的"兜底 `null`"分支上 → 页面当场进错误边界
     （`Cannot read properties of null (reading 'items')`）。修法是让外壳 mock 对
     列表类命令给**契约形状的空页**（`{items: [], nextPage: null}` / `{repos: []}`）。

   第 3 条同时暴露一个值得记录的产品边界：**这些页面在收到 `null` 载荷时会整页崩**
   （T3.8 曾对快照页的同类问题做过"宽容 null"处理，见提交 `5758002`）。
   按契约后端不会返回 `null`，所以本轮不改产品（避免与在飞的 M4 分支冲突）；
   若要统一，应作为一次独立的小重构：所有列表页把 `?? []` 补到读取点。
