# 02 · 历史、分支与远端同步

## 提交历史（DAG）

「历史」页用一张可交互的**提交图**呈现历史：

- 分支泳道着色稳定，同一分支刷新后颜色不变；
- 支持缩放、平移与**迷你地图**；大仓库按需分页加载，滚动到底部自动取下一页；
- 点击提交查看**详情**（元信息、文件列表、diff、父提交跳转、复制 hash）；
- 顶部可**筛选**（分支、作者、时间等）与**搜索**提交信息，结果可跳转定位。

图与详情可切换**图模式 / 列表模式**；开发构建下还有性能面板可查看布局与绘制耗时。

## 分支与标签

「分支」页管理分支与标签：

- **创建**分支（从当前 HEAD）、**切换**、**重命名**、**删除**；
- 设置 / 取消**上游跟踪**；
- 标签支持**轻量**与**附注**两种，可推送与删除。

切换前若工作区有未提交改动，应用会提示并给出手续（暂存或储藏）。

## 远端同步

「分支」页顶部提供同步操作，长任务（fetch/pull/push）显示进度且可取消：

- **fetch**：全部或单个远端，可选 `--prune`；
- **pull**：策略可选 fast-forward-only / merge / rebase（可在设置里设默认）；
- **push**：普通推送、设置上游，以及在**被拒绝**时使用 `--force-with-lease`。

> 被拒（non-fast-forward）时提供三选项：`force-with-lease`（会展示远端当前提交）、先 pull、取消。
> 为了安全，**不提供裸 `--force`**。

pull 若产生冲突，会进入「冲突」页的三栏向导（见 [`03-conflicts-rebase-safety-net.md`](03-conflicts-rebase-safety-net.md)）。

## 储藏与历史改写

「历史」页的操作面板提供：

- **stash**：保存 / 应用 / 弹出 / 删除，可查看 diff 与命名；
- **cherry-pick**、**revert**、**reset**（reset 带计划预览与快照）；
- **reflog**：查看引用日志，并从任意点恢复为一个新分支（不移动现有分支）。

所有写操作都会先打快照并记录审计。
