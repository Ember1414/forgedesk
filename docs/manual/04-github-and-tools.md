# 04 · 代码托管、终端、编辑器与扩展

## 代码托管（GitHub）

**登录**：设置 → 代码托管账号，支持 **OAuth 设备码**（复制码 → 打开浏览器 → 自动轮询）与 **PAT**。
令牌存入系统钥匙串，重启保持登录；可添加多个账号并为仓库绑定指定账号。

**仓库面板**：我的 / 星标 / 组织 / 搜索；可 Clone（选择账号）、Fork、Star、Watch；
README 以安全方式渲染（阻止脚本执行）。

**拉取请求（PR）**：列表与筛选 → 详情（描述、时间线、变更文件与内联 diff）→
**行内评论**（定位到行，越界本地拒绝）→ 提交 Review（Approve / Request changes / Comment）→
**合并**（merge / squash / rebase，可选删除源分支）。

**议题（Issues）**：列表、筛选、创建、编辑、评论、关闭、指派。

**流水线（Actions）**：workflow 与运行记录、状态、**日志流式加载**、重跑与取消。

> 触发限流时会显示剩余额度与重置时间，并自动降级为缓存数据（ETag）。

## 内嵌终端

「终端」页提供多标签终端：

- 支持交互式命令、中文与 emoji、复制粘贴与搜索；
- 执行 `git commit` 等命令后，界面状态自动刷新；
- 输入**危险命令**（如 `git reset --hard`）会出现非阻塞提示条，并提供「转到图形安全操作」；
  执行后应用会额外补打一个快照。

> `git rebase -i` 这类需要编辑器的交互命令在内嵌终端里不可用——请改用应用内的
> **拖拽式 rebase**（可视化、可预览、可回滚）。

## 命令解释与错误诊断

- 「命令字典」（侧栏 → 命令字典）解释常见 git 命令与参数，含风险提示；
- 操作失败时报错卡片会给出**可读原因**与**可点击的修复动作**，并保留最近的诊断历史。

## 编辑器

「编辑器」页含文件树与 Monaco 编辑器：多标签、脏标记、语法高亮、基础补全，以及
**文件历史 / blame**。

当文件在外部被修改时，保存会给出三选一：**覆盖 / 保留 / 并排对比**——绝不静默覆盖。

## 命令面板与快捷键

`Ctrl/Cmd+Shift+P` 打开**命令面板**，搜索并执行命令（导航、刷新、主题等）。
快捷键可在设置 → 快捷键中自定义，冲突会被检测并阻止保存，可一键恢复默认；还有布局预设可持久化。

## 插件

「插件」页（或 设置 → 插件）管理插件：安装 / 授权 / 启用禁用 / 卸载 / 热重载，
并显示每个插件的权限与用量、日志。

- 插件在 **wasmi 沙箱**中运行，权限是**封闭白名单**：越权调用会被拒绝，宿主不会崩溃；
- 危险权限（写文件 / 写仓库 / 网络）在授权时醒目标注并要求二次确认；
- 插件崩溃被隔离，可在该插件的日志里查看原因；
- 已启用插件的**面板**会出现在仓库级「插件面板」页。

插件清单、权限与宿主 API 见 [`../PLUGIN-API.md`](../PLUGIN-API.md)。

## 主题与语言

设置 → 外观：明暗主题、跟随系统，以及**导入 / 导出主题 JSON**（内置两套原创主题）。
语言支持中 / 英，窗口标题跟随语言。

## 网络与密钥

设置 → 网络与密钥：代理（HTTP(S)/SOCKS5、`no_proxy`）、连通性测试，以及 SSH / GPG 管理。
代理对 fetch/push 与托管 API 同时生效，可按主机覆盖。
