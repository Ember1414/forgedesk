# 01 · 打开仓库、查看改动并提交

## 打开 / 克隆 / 初始化

在**仪表盘**点击「添加仓库」，或顶栏仓库切换器：

- **打开**：选择一个目录。选到子目录也没关系，应用会向上探测最近的仓库；
  若目录不是仓库，会给出明确提示与「初始化为仓库」动作。
- **克隆**：填远端 URL（HTTPS/SSH）与目标目录，可选深度克隆；进度在任务栏显示，可取消。
- **初始化**：创建新仓库，可选默认分支名。

打开后侧栏的仓库级入口（工作区 / 历史 / …）才会启用；未打开仓库时它们是禁用态。

## 工作区状态

「工作区」页把改动分成三组：**已暂存 / 未暂存 / 未跟踪**，可切换**树**与**平铺**视图，
支持全选、批量暂存/取消暂存，并带有忽略文件开关。大仓库下列表为虚拟滚动，不会卡死。

## Diff 与暂存

选中文件查看 diff：可切换**统一 / 并排**模式，hunk 可折叠，支持复制与导出。

暂存粒度有两种：

- **块级（hunk）**：在 diff 上按块暂存/取消暂存；
- **行级（line）**：精确到行。

结果与 `git diff --cached` 一致（这一点有自动化对拍测试保证）。

## 提交

提交是一个**两段式**流程：

1. 填写提交信息（首行摘要 + 可选正文，带字数提示与过长警告）；
2. 点「提交」进入**预览**：展示文件清单、签名状态、将要执行的**钩子**以及**等价的 git 命令**；
3. 确认后才真正执行。取消不会改动仓库。

若 `pre-commit` 等钩子拒绝提交，预览会展示钩子的原始输出，并提供「跳过钩子重试」的选项；
失败不会产生半成品提交。

## 修改最后一次提交（amend）

在提交面板选择 amend：可只改提交信息，或把当前改动并入上一次提交。

## 放弃修改（discard）

对单个文件或选中内容选择「放弃修改」，会先弹出**预览与二次确认**，确认后文件内容恢复为
`git checkout --` 的结果。放弃操作是破坏性的，因此同样记录在审计里。

## 文件监听

应用监听仓库文件变化，外部编辑后状态列表自动刷新（可在设置里关闭，关闭后退回轮询）。
