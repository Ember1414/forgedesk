# 状态面板性能基准（M1 / T1.4）

## 场景

- 10000 个未暂存变更文件（分 100 个目录），树视图（默认）。
- 测量：从页面导航到第一行文件可见的时间（首屏），Chromium（系统 Edge）+ mock IPC。

## 结果（2026-09-24，本机 Windows，多次运行取代表性值）

| 运行 | 首屏耗时 |
| --- | --- |
| 1 | 380ms |
| 2 | 419ms |
| 3 | 425ms |
| 4 | 441ms |
| 5 | 495ms |

结论：**全部 < 500ms，满足验收 < 1s**（验收口径见 `docs/AGENT-PROMPTS.md` T1.4 第 5 条）。
VirtualList 窗口化保证滚动只渲染可视行；分组计数与树聚合为 O(n) 纯函数（约 10ms/万条）。

## 复现

```bash
pnpm dev        # 终端 1
pnpm test:e2e   # 终端 2：e2e/workspace.spec.ts 的性能用例会输出实测毫秒数
```

## 口径说明

浏览器层测量（mock IPC 返回 JSON）：真实桌面运行时额外包含 git status 的
进程/索引读取时间——该部分属于 T1.3 已验证的 GitProcess 路径，与面板渲染无关。
