## 4. 依赖与取舍

provider 新增 workspace 已有的 `sha2` 直接依赖，用于缓存身份摘要。沿用锁定版本，不新增传递依赖，
不引入网络服务；相比保存明文令牌或自制非加密散列，能减少凭据在缓存键中的暴露与碰撞风险。
合规检查重新运行；许可证图不变，无需变更许可审计内容。尚未测量最终桌面可执行文件的体积差异。

草稿保留限于当前进程，不提供崩溃恢复；终端回放限 1 MiB，会截断旧内容，复杂全屏 TUI 的重建仍需单独验收。
本批测试使用临时仓库、本地 HTTP 服务及模拟宿主，未向真实远端写入。

## 5. 后续优化建议

以下属于审查中的进一步优化，本批没有把它们计入修复成效：

1. 历史仍观察所有已加载页。应设计可回收页窗口与增量模型，减少 refs 后全页重取和重复合并。
2. 后端深分页仍可能反复从 tip revwalk。应在真实仓库测量，再评估增量 walker 或批量读取。
3. 多数路由仍静态加载；生产构建仍有大 chunk 与无效动态导入提示。后续按功能延迟加载并测 WebView 启动。
4. 日志行仍 append 时复制累计数组，未增加分块存储/内存上限；超大 Actions 日志需补专项压测。
5. 全局搜索的实际检索、导航信息层级、危险操作区收纳，以及更多系统缩放与 macOS/Linux WebView 验收继续按审查建议推进。

本批无需额外人类审批；发布、跨平台真实宿主验收及上述后续优化未包含在本次完成声明中。
