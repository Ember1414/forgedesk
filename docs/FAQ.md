# 常见问题（FAQ）

> 使用中遇到报错请先看 [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md)；仍未解决再到仓库 issue 提问。

## 产品与范围

**1. ForgeDesk 是什么？**
开源、跨平台、可自由分发的 Git 图形化桌面工作台，把复杂的 Git/代码托管操作变成可视化界面、向导与可交互图表。

**2. 它是免费的吗？需要付费订阅吗？**
完全免费，Apache-2.0 许可，**零付费服务依赖**；无付费墙、无强制登录。

**3. 需要注册账号才能用吗？**
不需要。本地 Git 功能完全离线可用；只有使用代码托管功能（如查看/创建 PR）时才需要登录你**自己的**托管账号。

**4. ForgeDesk 含 AI 功能吗？**
**不含。** 不做模型推理，不生成提交信息，不自动解决冲突。开发过程使用 AI 辅助编码，但产品本身零 AI、可完全离线工作。

**5. 支持哪些平台？**
Windows / macOS / Linux 同源构建。当前发布策略为 **Windows 优先**；macOS 与 Linux 真机验证按 [`adr/ADR-005-defer-cross-platform-verification.md`](adr/ADR-005-defer-cross-platform-verification.md) 暂缓。

**6. 会不会把我的代码或使用数据上传？**
不会。代码内容不上传、无遥测 SDK；详见 [`PRIVACY.md`](PRIVACY.md)。

**7. 现在能下载安装包吗？**
M7 正在推进安装包与发布流水线，**预编译版本尚未提供**。目前可从源码构建（见 [`../README.md`](../README.md)）。

## 日常使用

**8. 怎么打开一个本地仓库？**
仪表盘的「添加仓库」→ 打开 / 克隆 / 初始化。也可以直接选择含仓库的子目录，应用会向上探测。

**9. 如何只暂存文件里的一部分改动？**
在 diff 视图里按 **块（hunk）** 或**行**暂存/取消暂存；结果与 `git diff --cached` 一致。

**10. 提交前能看到将要执行的命令吗？**
能。提交走「预览 → 确认」两段式，预览里展示文件清单、签名状态、将要执行的钩子，以及**等价的 git 命令**。

**11. 误操作了怎么救回来？**
破坏性操作（reset --hard / rebase / clean / checkout -f / stash drop 等）执行前会自动打**快照**；在「操作历史 / 快照」页可一键回滚，回滚后会校验仓库一致性。

**12. 为什么 push 被拒绝后没有 `--force` 选项？**
出于安全，仅提供 **`--force-with-lease`**（先 fetch 再确认远端实际提交），**不提供裸 `--force`**。

**13. 冲突怎么解决？**
冲突会进入**三栏向导**：逐块「采用本地 / 采用远端 / 两者保留 / 手动编辑」，标记解决后 continue；merge / rebase / cherry-pick 冲突共用同一向导。

**14. 能在界面里做交互式 rebase 吗？**
能。可拖拽排序并对提交设置 reword / squash / fixup / drop / edit，实时预览新历史，执行前可取消。

**15. 怎么管理多个托管账号？**
设置 → 代码托管账号，可添加多个账号并为仓库绑定指定账号。

**16. 公司网络要走代理怎么办？**
设置 → 网络与密钥：支持 HTTP(S)/SOCKS5、`no_proxy` 列表与连通性测试；代理对 fetch/push 与托管 API 同时生效。

**17. 提交签名（GPG/SSH）支持吗？**
支持提交时启用签名，并在提交详情展示验证状态（Verified）。

**18. 有内嵌终端吗？**
有。终端里执行 `git commit` 后界面状态会自动刷新；执行危险命令会给出提示并提供「转到图形安全操作」。

## 数据与隐私

**19. 我的令牌存在哪里？**
系统凭据库（keyring）：Windows 凭据管理器 / macOS Keychain / Linux Secret Service；SQLite 里只存引用，明文永不落盘。

**20. 应用数据放在哪？能删吗？**
Windows `%APPDATA%\io.github.ember1414.forgedesk`；macOS `~/Library/Application Support/...`；Linux `~/.local/share/...`。可随时删除（会清空设置、日志、快照与插件）。

**21. 日志会上传吗？**
不会。日志是本地文件，写入前已脱敏，可随时查看或删除。

## 扩展与定制

**22. 能装插件吗？**
能。插件运行在 wasmi 沙箱中，按清单声明的权限逐项授权；有 3 个示例插件与 SDK，见 [`PLUGIN-API.md`](PLUGIN-API.md)。

**23. 能换主题 / 换语言吗？**
能。内置明暗与两套原创主题，支持导入导出主题 JSON；中英双语，可扩展语言包。

**24. 怎么参与贡献？**
见 [`../CONTRIBUTING.md`](../CONTRIBUTING.md)（含开发环境、门禁命令、i18n 与插件贡献流程）。
