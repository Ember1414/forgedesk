关于 ForgeDesk

A Git client for everyone · 看得见的 Git，不只是命令行。

项目定位

ForgeDesk 是一个开源、跨平台、可自由分发的 Git 与 GitHub 图形化桌面工作台：把终端里易错的 Git 操作变成可视化界面、向导与可交互图表。 基于 Tauri 2 + Rust 构建，Windows / macOS / Linux 三平台。

两条硬承诺

  • 不含任何 AI / 机器学习推理功能。 没有"AI 生成提交信息"，也没有任何模型推理服务；数据不出你的机器 （联网行为仅有你主动发起的 GitHub 操作与应用更新检查，详见 隐私说明）。
  • 零成本分发，无付费墙。 不购买代码签名证书、不上付费商店；代价是首次安装时系统可能多问一句， 处理步骤见下载页的信任说明。

安全网

所有破坏性 Git 操作（重置、变基、强推等）一律经过 "计划预览 → 快照 → 执行 → 可回滚"；push --force 在产品里不可用，只允许更安全的 --force-with-lease。 这不是营销话术，是写进架构约束的红线。

参与与反馈

问题反馈与功能建议走 GitHub Issues， 安全问题请遵循 安全策略； 贡献流程见 CONTRIBUTING。
