校验下载（三平台命令）

把安装包与同一次发布里的 SHA256SUMS 下载到同一目录，计算哈希后与同名的行逐字比对 （大小写不敏感）。

Windows（PowerShell）

Get-FileHash .\ForgeDesk_<版本>_windows_x64.exe -Algorithm SHA256

macOS（终端）

shasum -a 256 ForgeDesk_<版本>_macos_aarch64.dmg

Linux（终端）

sha256sum ForgeDesk_<版本>_linux_amd64.AppImage

GPG 签名验证

发布流水线会用 GPG 对 SHA256SUMS 做分离签名（SHA256SUMS.asc）。 有了公钥后，验证命令： 

gpg --verify SHA256SUMS.asc SHA256SUMS

下载 GPG 公钥（gpg-pubkey.asc）

v1.0.0 的 SHA256SUMS.asc 已随 Release 附件提供，但 公钥文件尚未随站发布， 因此上面的验证命令暂时无法直接使用。当前可用 SHA256SUMS 核对下载是否完整（防传输损坏）； 公钥与指纹的自动发布见 docs/RELEASE.md。

安装与信任说明

本项目是零成本分发的开源软件，没有购买付费代码签名证书， 因此系统可能在你第一次运行时多问一句。这不是木马特征，是签名缺失的正常表现。

Windows

首次运行可能被 SmartScreen 拦截：选择「更多信息 → 仍要运行」； 或改用免安装的便携版 zip（解压即用）。安装前建议先完成上面的 SHA256 校验。 完整说明见 docs/install/windows.md。

macOS

应用使用 ad-hoc 签名（Apple Silicon 上必需）。首次打开若提示"无法验证开发者"： 右键点击应用 →「打开」，或到 系统设置 → 隐私与安全性 → 点「仍要打开」； 若提示"已损坏"，执行 xattr -dr com.apple.quarantine /Applications/ForgeDesk.app 去除隔离标记。完整步骤见仓库 docs/install/macos.md。

系统要求

Windows 10 1809 或更高（需 WebView2，Windows 11 已内置）；macOS 10.15+；Linux 需 WebKitGTK 4.1（依赖随发行版包提供）。应用本身不含 AI 功能、不含遥测， 本地 Git 操作完全离线可用。
