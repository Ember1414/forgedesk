ForgeDesk

A Git client for everyone · 看得见的 Git，不只是命令行。

状态：尚无可用版本
  • 开源、跨平台（Windows / macOS / Linux）的 Git 与 GitHub 桌面工作台
  • 把终端里易错的 Git 操作变成可视化界面、向导与可交互图表
  • 破坏性操作自动打快照，随时一键回滚
  • 不含任何 AI 功能；无遥测；本地 Git 操作完全离线可用

下载

尚未发布任何正式版本。 前往 Releases 查看是否已有可用构建；源码构建方式见仓库的 README。

Windows 首次运行可能被 SmartScreen 拦截（本项目未购买代码签名证书）： 选择「更多信息 → 仍要运行」，或改用免安装的便携版 zip。 完整说明见仓库 docs/install/windows.md。

校验下载

  1. 把安装包与同一次发布里的 SHA256SUMS 下载到同一目录。
  2. 在 PowerShell 里计算安装包的哈希（把文件名换成你下载的那个）：
Get-FileHash .\ForgeDesk_<版本>_windows_x64.exe -Algorithm SHA256
查看当前版本的校验和（SHA256）

以下数值来自同一次发布生成的 SHA256SUMS，与 Release 附件内容一致。

  1. 与 SHA256SUMS 里同名的行逐字比对（大小写不敏感）。
  2. 若该次发布附带 SHA256SUMS.asc，可用 gpg --verify SHA256SUMS.asc SHA256SUMS 再验一层签名（公钥发布方式见仓库 docs/RELEASE.md）。
