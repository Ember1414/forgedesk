ForgeDesk

A Git client for everyone · 看得见的 Git，不只是命令行。

开发中 · 尚无可用版本
  • 开源、跨平台（Windows / macOS / Linux）的 Git 与 GitHub 桌面工作台
  • 把终端里易错的 Git 操作变成可视化界面、向导与可交互图表
  • 破坏性操作自动打快照，随时一键回滚
  • 不含任何 AI 功能；本地 Git 操作完全离线可用
