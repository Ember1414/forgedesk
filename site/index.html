界面示意（非真实截图）

它能做什么

  • 看得见的历史 提交历史是可交互的泳道图：点选即看详情，分支与合并一目了然。
  • 向导代替命令 合并、变基、解决冲突都走"预览计划 → 确认 → 执行"，每一步先看清楚再动手。
  • 敢做的安全网 破坏性操作自动打快照，push 只允许 force-with-lease，随时一键回滚。
  • 本地与私密 不含任何 AI 功能、没有遥测；凭据只存系统钥匙串，离线完全可用。

三步开始

  1. 下载并校验 安装器或便携版任选；下载页给出每个产物的 SHA256 与三平台校验命令。
  2. 安装并打开 首次运行的系统提示（SmartScreen / Gatekeeper）都有对应说明，不是木马特征。
  3. 打开你的仓库 克隆或打开本地目录即可；之后的破坏性操作都会先打快照。

一些不吹牛的数字

  • 301 ms 打开 10 万提交的仓库（仓库内 perf_probe 实测）
  • ~8 MB Windows 安装包大小（v1.0.0 实测，不含浏览器内核）
  • 0 遥测请求与 AI 功能；数据清单见隐私说明
  • Apache-2.0 开源许可，永久免费，可自行构建

为谁而做

如果 rebase --onto、cherry-pick 这些词让你紧张，ForgeDesk 把它们变成看得见的计划与可回滚的操作； 如果你本就是命令行熟手，它也能当成本地 GitHub 工作台与可视化速查工具。

  • 刚接触 Git 的学生与转行者
  • 想少敲命令的日常开发者
  • 需要可视化讲解的教师与分享者
  • 不允许数据离开本机的团队

技术说明

基于 Tauri 2 + Rust：Git 读操作走 libgit2、写操作走系统 git CLI， 界面用系统自带的 WebView 渲染——没有 Electron、不捆绑浏览器内核， 安装包保持在小体积量级。开源许可见 许可证页，数据与网络行为见 隐私说明。

本站的版本信息来自发布清单（与应用内自动更新同一份数据）。尚无发布时如实显示"无可用版本"， 不提供任何虚假下载入口。
